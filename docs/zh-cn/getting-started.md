# 快速开始

> **教程** —— 本课将带你安装 VexGo、首次登录并发布第一篇文章，全程约 5 分钟。

本教程面向完全的新手。学完你将拥有一个运行中的 VexGo 实例，并成功发布一篇博客文章。

## 开始之前

你需要准备：

- 一台运行 **Linux** 或 **macOS** 的机器（或安装了 **Docker** 的机器）
- 可用的网络连接
- 一个浏览器

无需任何 Go、React 或数据库知识。

## 第 1 步：启动 VexGo

选择最适合你的方式，两者启动的是同一个服务器。

### 方式 A：使用 Docker 运行（推荐用于试用）

如果你已安装 Docker：

```bash
docker run -d --name vexgo -p 3001:3001 -v ./data:/app/data ghcr.io/vexgo-org/vexgo:latest
```

### 方式 B：直接运行二进制文件

1. 前往[发布页面](https://github.com/vexgo-org/vexgo/releases)，下载对应系统和架构的二进制文件（例如 `vexgo-linux-amd64`）。
2. 赋予执行权限并运行：

```bash
chmod +x vexgo-linux-amd64
./vexgo-linux-amd64
```

> **刚才发生了什么？** VexGo 在 `3001` 端口启动了一个 HTTP 服务器，并在 `./data` 目录创建了 SQLite 数据库。这就是整个服务器——无需单独安装数据库。

## 第 2 步：打开网站

打开浏览器访问：

```
http://127.0.0.1:3001
```

你应该能看到 VexGo 首页。

## 第 3 步：登录

1. 点击右上角的**登录**。
2. 使用默认超级管理员账号：

   | 字段 | 值                  |
   | ---- | ------------------- |
   | 邮箱 | `admin@example.com` |
   | 密码 | `password`          |

3. 点击**登录**。

## 第 4 步：修改默认密码

默认密码是公开信息——在做其他事情之前请先修改它。

1. 点击右上角头像，进入**个人资料**页面。
2. 修改密码并保存。

> **安全提示：** 任何能访问你实例的人都可以用默认账号登录。请立即修改密码，并在公网部署前设置强 `JWT_SECRET`。生产环境加固请参考[部署指南](/zh-cn/guides/deployment)。

## 第 5 步：发布第一篇文章

1. 点击**写文章**（或导航栏中的**写作**入口）。
2. 输入标题，例如：`你好，VexGo！`
3. 在 Markdown 编辑器中撰写正文。
4. 选择一个**分类**（默认分类已存在）。
5. 点击**发布**。

你的文章现在出现在首页，所有访问者都能看到。

## 第 6 步：探索管理面板

使用超级管理员账号，你可以管理整个站点，包括：

- 审核**待审的文章和评论**（若启用审核）
- 管理**用户和角色**
- 修改**站点设置**（站点名称、注册、验证码等）
- 安装和切换**主题**
